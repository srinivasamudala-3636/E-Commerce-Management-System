# E-Commerce Management System

## Project Description
This project is developed using PostgreSQL to manage e-commerce business operations such as customers, products, suppliers, orders, payments, shipments, and employees.

## Technologies Used
- PostgreSQL
- SQL
- Visual Studio Code

## Database Tables
This project contains 14 tables:
1. Customers
2. Addresses
3. Categories
4. Suppliers
5. Products
6. Orders
7. Order_Items
8. Payments
9. Shipments
10. Reviews
11. Wishlist
12. Cart
13. Cart_Items
14. Employees

## SQL Concepts Covered
- DDL and DML Commands
- SELECT, WHERE and ORDER BY
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries
- Window Functions
- CTEs and Recursive CTEs
- Self Joins
- Transactions (COMMIT, ROLLBACK, SAVEPOINT)
- Indexing
- EXPLAIN ANALYZE

## Business Reports
1. Sales Dashboard
2. Top 10 Products Report
3. Customer Lifetime Value Report
4. Product Recommendation Query
5. Repeat Customer Analysis
6. Inventory Aging Report
7. Supplier Performance Dashboard
8. Monthly Growth Report
9. Revenue Forecast Dataset
10. Complete Business KPI Dashboard

## Project Files
- `Create_database.sql` – Database creation
- `create_table.sql` – Creates 14 tables
- `insert_sample_data.sql` – Inserts sample records
- `basic_queries.sql` – Contains 110 SQL questions and queries
- `E-Commerce ER Diagram.png` – Database relationship diagram

## How to Run
1. Install PostgreSQL.
2. Create the database.
3. Run `create_table.sql`.
4. Run `insert_sample_data.sql`.
5. Execute queries from `basic_queries.sql`.
